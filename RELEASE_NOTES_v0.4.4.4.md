# MRAPI DEV v0.4.4.4 — Roadmap Reopen Control

- Adds an explicit REOPEN BLOCKED MILESTONE action.
- Reopens the Goal as ACTIVE and the selected blocked milestone as PENDING.
- Clears stale mission/verification linkage so the milestone can start a fresh Autopilot attempt.
- Keeps prior blocked Mission/Runs as history; no old attempt is reused.
